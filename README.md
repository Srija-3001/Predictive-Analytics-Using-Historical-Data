# Predictive Analytics Using Historical Data

## Project Overview

This project uses historical sales data to build a predictive model and forecast future sales trends using Linear Regression.

## Features

* Historical data analysis
* Data preprocessing
* Linear Regression model
* Future sales prediction
* Trend visualization

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

## Dataset

Monthly historical sales data used to predict future sales trends.

## Outcome

Developed a predictive analytics model capable of forecasting future sales and visualizing business trends using historical data.
